❓ 待你实测确认的 8 个点
  1. position 映射：默认 对话开头→2(↑AN)、最新消息前→3(↓AN)。若 Tavo 的 2/3 是「作者注释前/后」而不是聊天流位置，可能该改成 5(↑EM) / 4 + depth:0。请实测哪个位置真的出现在对话开头 / 最新消息前。
  2. order 来源：默认把 Rikkahub priority 直传 Tavo order。Tavo 里 order 是小=先注入还是大=先注入？若方向相反，我加个「取反」开关。
  3. entries 形式：示例是对象 "0"…；数组是否也能导入？我在选项里留了切换。
  4. uid / display_index：输出统一重排为 uid=0..n-1，display_index=1..n（与示例一致）。若 Tavo 要求 display_index 从 0 开始，告诉我。
  5. name 与 comment：示例里两者完全相同，我也照抄。若 Tavo 只用其中一个，可以只写一个。
  6. 顶层 name / description：Tavo 示例顶层没有，我按示例丢弃（仅用于下载文件名）。如果 Tavo 接受顶层 name/description，我加上。
  7. 数值范围：我按 Rikkahub 的 ±999999999 直传 depth / scanDepth / order。Tavo 是否接受负数？（Rikkahub 示例里 injectDepth 有 0 和 49。）
  8. useProbability / probability：Rikkahub 无此概念，我默认 true / 100（= 总是激活）。若 100 不等于「必定触发」，需要改成别的值。
